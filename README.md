# 🎯 Number Guessing Game (Python)

A simple interactive number guessing game built in Python.  
This project helped reinforce control flow, loops, and user input handling.

---

## 🎮 Gameplay Overview

- The computer randomly selects a number between 0 and 10.
- The user keeps guessing until they get it right.
- After each incorrect guess, the correct number is revealed.
- The number of attempts is tracked and displayed after each guess.

---

## 🧠 Features

- Random number generation using `random.randint()`.
- Input validation and loop repetition.
- Guess counter that tracks number of attempts.
- User feedback after every guess.

---

## 🛠 Technologies Used

- **Python 3**
- Standard Python library: `random`
